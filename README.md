# Christmas Shop

A responsive Christmas-themed website built from a Figma design as part of the RS School JavaScript/Frontend Pre-School course.

## Demo

https://maksimr02.github.io/christmas-shop/

## Technologies

- HTML5
- CSS3
- JavaScript
- Git

## Features

- Responsive and adaptive layout
- Mobile navigation menu
- Interactive image slider
- Scroll-to-top button on mobile devices
- Two-page website
- Internal page navigation
- Layout adapted for desktop, tablet, and mobile screens

## What I Practiced

During this project, I practiced:

- Converting a Figma design into a responsive and adaptive layout
- Semantic HTML
- Responsive web design
- CSS media queries
- DOM manipulation
- Event handling
- JavaScript functions
- Working with browser events such as `scroll` and `resize`
- Git and GitHub workflow

## Project Structure

- `index.html` — main page
- `gift.html` — gifts page
- `css/` — styles
- `assets/` — images, icons, and SVG files
- `index.js` — JavaScript functionality

## About the Project

This project was completed as part of the RS School JavaScript/Frontend Pre-School course.

The main goal of the project was to practice building a responsive website from a Figma design, implementing interactive UI elements with JavaScript, and adapting the layout for different screen sizes.
